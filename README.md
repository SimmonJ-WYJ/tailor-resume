# Tailor Resume · 岗位定制简历

根据原始简历和目标公司的岗位 JD，定制真实、相关的简历。支持中文、英文或中英文两个独立版本，并指导 AI 生成可下载的 Word 和 PDF。

## 功能

- 基于岗位要求调整经历顺序、个人简介、项目描述和技能表达。
- 不编造经历、职责和成果数字，区分个人贡献与团队成果。
- 中英文可以跨语言输入和输出；双语版本保持事实一致。
- 可选生成与简历一致的面试自我介绍和项目讲述。

## 安装到 Codex

下载仓库 ZIP 并解压，将包含 `SKILL.md` 的 `tailor-resume` 文件夹放入 `~/.codex/skills/`。如果解压后的文件夹带有分支名后缀，先重命名为 `tailor-resume`。然后在新会话中使用 `$tailor-resume` 调用。

本仓库是 Skill 指令包，需要在支持 Skill、文件读取、DOCX 生成和 PDF 转换的 AI 环境中运行。它不是独立网站，也不提供公共上传入口。不同环境的文档工具能力不同，安装 Skill 本身不会安装文档转换引擎。

## 使用示例

上传自己的简历，然后发送：

```text
使用 $tailor-resume 定制我的简历。
目标公司：示例公司
目标岗位：产品设计师
岗位 JD：[粘贴完整岗位要求]
输出语言：中英文两个版本
文件格式：Word 和 PDF
要求：突出相关项目和个人贡献，不编造数据。
```

也可以选择“仅中文”或“仅英文”。没有选择语言时，Skill 会先询问。

后续修改示例：

```text
把第一个项目缩短，突出我的设计决策，然后重新导出两个语言版本。
```

## 交付与限制

通常交付所选语言的 DOCX 和 PDF；中英文双版本对应四个文件。运行环境缺少转换或渲染能力时，AI 应明确说明失败或未验证的部分，不能提供虚假下载链接。

本版本已进行 Skill 结构校验，尚未用真实简历完成端到端文档导出测试。不保证面试、录用或 ATS 评分结果。

## 隐私

在自己的私有 AI 会话中提供简历。不要把真实简历、联系方式或生成的个人文件提交到本仓库、Issues 或 Pull Requests。Skill 不包含账号、密钥或个人简历。
